# Title : Ingredient Library
## Repository 
https://github.com/boraforester-bit/Final_Project
## Description 
Keeps track of current ingredients in pantry and fridge, what they can be used for, and stores relevant recipes.
## Features 
- Feature 1 - allows for retrieval of current ingredients in pantry and fridge
- Feature 2 - Finds all recipes capable with current ingredients, or shows closest capable recipes and what’s needed to make them 
- Feature 3 - Stores kinds of recipes, including dinner, snacks, drinks, and how to make them/prepare certain produce
## Challenges
- Creating a database that can find the next-best option for recipes (if no recipes are available, which is the closest with 1-2 ingredients missing)
- Finding out how to make an easy input system that is intuitive and easier than simply looking in the fridge/pantry
-Making the system visually engaging and easy to traverse
## Outcomes
Ideal Outcome: 
- A fully functional system capable of obtaining possible recipe ideas from current ingredients, or next-best options. Allows for easy input of new recipes, how to make them, and new ingredients added to storage. User interface available and drop down menus.

Minimal Viable Outcome: 
- Allows for ingredients to be input into system, and checks to see if all ingredients are available for at least 5 recipes
## Milestones 
- Week 1 
1. Research and create basic design of program, including buttons/dropdown menus
2. Create basic input system for recipe names and needed ingredients
3. Create pantry/fridge storage section
- Week 2 
1. Create pantry/fridge storage section with area for input
2. Allow for ingredient storage to be easily interactive, allowing for deletion, addition of new ingredients, and case-insensitive input
3. Start on “check” system to tie current ingredients with required ingredients
- Week N (Final) 
1. Create “next-best” system to check for possible best recipes
2. Input multiple new recipes and tabs for recipes
